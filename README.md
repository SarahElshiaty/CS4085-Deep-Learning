# Deep Learning — CS 4085

This repository contains coursework, implementations, experiments, and projects completed as part of **CS 4085 – Deep Learning**.

## Course Overview

CS 4085 provides an in-depth study of neural networks and deep learning, with emphasis on building, improving, and applying deep learning models to practical problems.

The course covers techniques for improving neural networks, including hyperparameter tuning, regularization, and optimization, as well as major deep learning architectures and applications.

## Topics Covered

- Neural Networks and Deep Learning
- Hyperparameter Tuning
- Regularization
- Optimization Techniques
- Convolutional Neural Networks (CNNs)
- Sequence Models
- Time Series and Language Applications
- Generative Models
- Model Development and Evaluation
- Practical Deep Learning Applications
